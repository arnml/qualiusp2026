# Agent rules for this repository

Instructions for any AI agent working here (Claude Code, Codex, subagents).

## Qualification text (LaTeX) and Overleaf

- **`quali/` is the source of truth** for the master's qualification text. It is self-contained: `main.tex`, the class files, `bibli.bib`, `chapters/` and `figures/`.
- **Never render LaTeX locally.** All LaTeX builds happen in Overleaf, in the browser:
  - project `qualiusp2026`, folder `quali/`
  - main document `quali/main.tex`
  - compiler pdfLaTeX
- **Keep Overleaf in sync with the repo.** After any change to `quali/`:
  1. commit and push
  2. in Overleaf, **Refresh** each changed linked file (they were imported "From external URL" from `raw.githubusercontent.com/arnml/qualiusp2026/main/quali/...`)
  3. recompile
- If someone edits in Overleaf, copy the edits back into the repo before making new changes. Only one side is edited at a time.
- **Bibliography:** `bibli.bib` at the repo root is the master copy. Copy it into `quali/bibli.bib` whenever it changes. Add an entry only after checking it on its official page.
- The text describes only what the experiment reports support. `quali/EXPERIMENT_MAP.md` records which experiments the text uses; `experiments/HYPOTHESES.md` records the status of each claim.

## Experiments

- **One directory and one `uv` environment per experiment:** `experiments/expNN_name/`.
- **Pre-register before running.** Commit `PROTOCOL.md` (question, splits, metrics, decision rules, budget, priors) before scoring any evaluation data. Record deviations.
- **Adversarial review before running:** have Codex (`codex exec -s read-only`) argue for the null. Record the review in `experiments/reviews/`.
- **Writing up:** report nulls honestly; update `README.md`, `experiments/EXPERIMENTS.md`, `experiments/HYPOTHESES.md` and `SESSION_HANDOFF.md`.
- **GPU work** runs on Colab (free T4), one session at a time. Notebooks are generated by `make_notebook.py`, pinned to a commit, committed and pushed.

## Git and secrets

- Commit and push frequently. To push:
  1. `gh auth switch --hostname github.com --user arnml`
  2. `git push`
  3. `gh auth switch --hostname github.com --user amoyavt` (other processes use that account)
- Never print or commit API keys. Read `OPENAI_API_KEY` from the Windows user environment.
