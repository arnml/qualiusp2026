\chapter{Experiment Index}
\label{app:index}

Table~\ref{tab:index} lists every experiment carried out so far, in the order in which it was run. Each experiment answers one question. From experiment 3 onward, its protocol was registered in the project repository before the evaluation data were scored; every report is kept with the code (directory \texttt{experiments/expNN}). The status column follows Table~\ref{tab:claims}: \emph{confirmed} means that a pre-registered test with a fixed decision rule succeeded (the primary test unless marked secondary), \emph{null} that it failed, \emph{exploratory} that the result was not a registered test or the experiment was not pre-registered, and \emph{context} that the experiment motivated later work but is not used as evidence. Experiments marked ``---'' in the last column are not used in the main text.
