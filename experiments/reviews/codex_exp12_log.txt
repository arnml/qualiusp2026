# exp12 protocol: pair-matched one-shot control for the iterative ranker (pre-registered 2026-11-15)

## Why

All three reviews (`../reviews/SYNTHESIS.md`) flag the same confound in exp09 and exp11:
- M1-iter was trained on **18,101 pairs (1,132 steps)**, M1 on **8,338 (522 steps)**. The questions were the same.
- So "iteration wins" (exp09, H6) and "the iteration change is rank 2" (exp11, H9) may partly be "more training".

## Question

1. **Primary (H6, de-confounded):** with **identical training pairs, labels, order, steps and schedule**, does conditioning the query on the already-picked paragraphs still beat one-shot scoring?
2. **Secondary (H9, de-confounded):** is the change that adds *only* query conditioning, D = M1-iter âˆ’ M1-ctrl, still low-rank?

## The control model: M1-ctrl

- `train.py --mode ctrl` builds **M1-iter's exact example list**: the same questions (exp09's seeded 1,000), the same positives per step (the remaining gold), the same negative draws (seeded per question and step), the same shuffle, batch 16, lr 2e-5, 1 epoch, max length 512, seed 0, initialised from A1.
- **The only change: the query is the question alone,** with no " [SEP] " prefix of picked paragraphs.
- This was checked in code before registration: same length, identical (paragraph, label) sequence, and only the query strings differ.
- The resulting model has seen exactly what M1-iter saw, minus the conditioning. The positive mix also matches: later-hop gold is over-represented, as in M1-iter.
- **Not retrained:** M1 and M1-iter, frozen from exp09. M1-iter's rankings come from exp09 (identical to a re-run, exp10 check).

## Hardware and replication (decided before any training)

- **Hardware:** all exp12 training and inference run on a **Colab T4 GPU** (`exp12_colab.ipynb`, generated by `make_notebook.py`). Inputs are staged on Google Drive. M1-iter (exp09) was trained on CPU, so the primary compares a CPU-trained M1-iter with a GPU-trained M1-ctrl. The difference is floating-point only: the code, seed, pairs and order are the same.
- **Hardware-matched replication (descriptive, the replication gate):**
  - M1-iter is retrained on GPU with seed 0 (`m1_iter_s0`).
  - Seeds 1 and 2 of both models are trained (`m1_ctrl_s{1,2}`, `m1_iter_s{1,2}`). The seed changes the shuffle and dropout; the pairs are unchanged.
  - Reported: recall@5 of each seed pair (iterative vs one-shot) on test, the mean difference and its spread across seeds.
  - **"Replicates"** = M1-iter > M1-ctrl in all 3 GPU seed pairs.

## Pre-registered tests

1. **Primary (test, 400):** recall@5 of M1-iter (iterative) vs `ctrl_oneshot`, McNemar exact, two-sided Î± = 0.05.
   - **Success** = M1-iter higher and p < 0.05.
   - **Power:** exp09's comparable pair had 93 discordant questions. With about 90, the minimum detectable effect at 80% power is about **+0.07 recall@5**, and an effect around 0.05 has roughly 50% power. A null result therefore does not show "no effect" below about 0.07. In that case the CI is reported.
   - Reading the result:
     - **Success:** H6 survives the confound.
     - **Fail with M1-ctrl â‰¥ M1-iter:** the exp09 gain was more training, not iteration.
2. **Secondary (dev300 â†’ test):** gain gate: if recall@5(M1-iter) âˆ’ recall@5(`ctrl_iter`) on dev300 is below 0.05, the secondary is **not testable**.
   - Otherwise: r* = the smallest rank in {1, 2, 4, 8} with **â‰¥ 80%** recovery on dev300. Recovery = (R(g) âˆ’ R(ctrl_iter)) / (R(M1-iter) âˆ’ R(ctrl_iter)).
   - **Holds if both:**
     - r* â‰¤ 8
     - on test, the 95% paired-bootstrap CI of recovery for r* has a lower bound > 0.5 (the numerator and denominator are resampled together)
   - **Control:** `g_rand_r2` must recover less than half of `g_r2`.
3. **Descriptive:**

def examples(rows, mode, n_neg=6):
    """(query, paragraph, label). Negatives are seeded per (question, step), so step0 = iter's step-0 subset."""
    out = []
    for qi, r in enumerate(rows):
        _, paras = paragraphs_of(r)
        ch = chain(r)
        non = [i for i in range(len(paras)) if i not in ch]
        for t in range(len(ch) if mode in ("iter", "ctrl") else 1):
            rng = np.random.default_rng([qi, t])
            # exp12 ctrl: M1-iter's exact pairs and order, query = the question alone
            q = r["question"] if mode == "ctrl" else query(r["question"], [paras[i] for i in ch[:t]])
            out += [(q, paras[i], 1.0) for i in ch[t:]]
            out += [(q, paras[i], 0.0) for i in rng.choice(non, n_neg, replace=False)]
    return out


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--mode", choices=("iter", "step0", "ctrl"), required=True)
    ap.add_argument("--tag", required=True)
    ap.add_argument("--n-questions", type=int, default=2000)
    ap.add_argument("--batch", type=int, default=16)
    ap.add_argument("--lr", type=float, default=2e-5)
    ap.add_argument("--max-len", type=int, default=512)
    ap.add_argument("--save-every", type=int, default=500)
    ap.add_argument("--seed", type=int, default=0, help="torch + shuffle seed; 0 = exp09's M1-iter")
    ap.add_argument("--smoke", type=int, default=0, help="run this many steps, report throughput, save nothing")
    args = ap.parse_args()
    torch.manual_seed(args.seed)

    rows = load("train")
    # seeded random subset (deviation 1 in results/budget.json: the train ids are sorted, so "first N" = 2-hop only)
    rows = [rows[i] for i in sorted(np.random.default_rng(9).permutation(len(rows))[: args.n_questions])]
    pairs = examples(rows, args.mode)
    out = MODELS / args.tag
    out.mkdir(parents=True, exist_ok=True)
    ckpt = out / "checkpoint.pt"
    print(f"mode={args.mode} questions={len(rows)} pairs={len(pairs)} pos={sum(p[2] for p in pairs):.0f}", flush=True)

    tok = AutoTokenizer.from_pretrained(str(A1))
    model = AutoModelForSequenceClassification.from_pretrained(str(A1)).to(DEV)
    opt = torch.optim.AdamW(model.parameters(), lr=args.lr, weight_decay=0.01)
    total = math.ceil(len(pairs) / args.batch)
    warm = max(1, int(0.1 * total))
    sched = torch.optim.lr_scheduler.LambdaLR(
        opt, lambda s: min(1.0, (s + 1) / warm) * max(0.0, (total - s) / max(1, total - warm)))
    step, secs = 0, 0.0
    if ckpt.exists() and not args.smoke:
        st = torch.load(ckpt, map_location=DEV)
        model.load_state_dict(st["model"]); opt.load_state_dict(st["opt"]); sched.load_state_dict(st["sched"])
        step, secs = st["step"], st["secs"]
        print(f"resumed at step {step}/{total}", flush=True)
    order = list(range(len(pairs)))
    random.Random(args.seed).shuffle(order)
    model.train()
    t0 = time.time()
    while step < total:
        idx = order[step * args.batch:(step + 1) * args.batch]
        q, p, y = zip(*(pairs[i] for i in idx))
        enc = encode(tok, list(q), list(p), args.max_len).to(DEV)
        loss = torch.nn.functional.binary_cross_entropy_with_logits(model(**enc).logits.squeeze(-1), torch.tensor(y, device=DEV))
        opt.zero_grad(); loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step(); sched.step(); step += 1
        if step % 50 == 0 or (args.smoke and step % 10 == 0):
            el = secs + time.time() - t0
            print(f"step {step}/{total} loss {loss.item():.4f} {el / 60:.1f} min, eta {el / step * (total - step) / 60:.0f} min",
                  flush=True)
        if args.smoke and step >= args.smoke:
            rate = (time.time() - t0) / step
            print(json.dumps({"sec_per_step": round(rate, 2), "steps": total, "projected_h": round(rate * total / 3600, 2)}))
            return
        if step % args.save_every == 0:
            torch.save({"model": model.state_dict(), "opt": opt.state_dict(), "sched": sched.state_dict(),
                        "step": step, "secs": secs + time.time() - t0}, ckpt)
    model.save_pretrained(out / "model"); tok.save_pretrained(out / "model")
    (out / "train_info.json").write_text(json.dumps(
        {**vars(args), "device": DEV, "questions": len(rows), "pairs": len(pairs), "steps": total,
         "train_minutes": round((secs + time.time() - t0) / 60, 1)}, indent=1))
    ckpt.unlink(missing_ok=True)
    print("done", flush=True)

def state(name):
    return {k: v.float() for k, v in load_file(str(DIRS[name] / "model.safetensors")).items()}


def lowrank(base, d, r, rand=False, seed=0):
    """As exp06/exp11: rank-r truncated SVD of each 2-D delta, 1-D deltas in full; rand = norm-matched random rank r."""
    g, out = torch.Generator().manual_seed(seed), {}
    for n in base:
        if d[n].dim() == 2 and min(d[n].shape) > r:
            U, S, Vh = torch.linalg.svd(d[n], full_matrices=False)
            part = (U[:, :r] * S[:r]) @ Vh[:r]
            if rand:
                R = torch.randn(d[n].shape[0], r, generator=g) @ torch.randn(r, d[n].shape[1], generator=g)
                part = R * (part.norm() / R.norm())
            out[n] = base[n] + part
        else:
            out[n] = base[n] + d[n]
    return out


def configs(extra=()):
    S = {k: state(k) for k in ("M1-iter", "M1-ctrl")}
    base, d = S["M1-ctrl"], {n: S["M1-iter"][n] - S["M1-ctrl"][n] for n in S["M1-ctrl"]}
    c = {"ctrl_oneshot": (lambda: base, False), "ctrl_iter": (lambda: base, True)}  # M1-iter endpoints: exp09 rankings (identical, exp10 check)
    for r in (1, 2, 4, 8):
        c[f"g_r{r}"] = (lambda r=r: lowrank(base, d, r), True)
    c["g_rand_r2"] = (lambda: lowrank(base, d, 2, rand=True), True)
    for tag in extra:  # seed replicates trained on GPU: models/<tag>/model; m1_iter_* run iteratively, m1_ctrl_* one-shot
        sd = lambda tag=tag: {k: v.float() for k, v in load_file(str(MODELS / tag / "model" / "model.safetensors")).items()}
        c[tag] = (sd, tag.startswith("m1_iter"))
    return c


def build(sd):
    m = AutoModelForSequenceClassification.from_pretrained(str(DIRS["A1"]))
    missing, unexpected = m.load_state_dict(sd, strict=False)
    assert not unexpected and all("position_ids" in k for k in missing), (missing, unexpected)
    return m.eval().to(DEV)


@torch.no_grad()
def rank_all(model, tok, rows, iterative):
    """exp09 inference: one-shot sort, or 4 greedy steps with the tail ordered by the step-3 scores."""
    def score(q, ps):
        return model(**encode(tok, [q] * len(ps), ps).to(DEV)).logits.float().cpu().squeeze(-1).reshape(-1).tolist()

    orders = []
    for r in rows:
        _, paras = paragraphs_of(r)
        rest, order = list(range(len(paras))), []
        for _ in range(STEPS if iterative else 1):
            s = score(query(r["question"], [paras[i] for i in order]), [paras[i] for i in rest])
            ranked = [i for _, i in sorted(zip(s, rest), key=lambda z: -z[0])]
            if not iterative:
                order = ranked
                break
            order.append(ranked[0]); rest = ranked[1:]
        orders.append(order + (rest if iterative else []))
    return orders


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--split", default="dev300", choices=("dev300", "test"))
    ap.add_argument("--only", nargs="*")
    ap.add_argument("--smoke", type=int, default=0)
    ap.add_argument("--extra", nargs="*", default=[], help="seed-replicate model tags under MODELS_DIR")
    args = ap.parse_args()
    tok = AutoTokenizer.from_pretrained(str(DIRS["A1"]))
    rows = load(args.split)[:args.smoke or None]
    out = Path(os.environ.get("RESULTS_DIR", HERE / "results")) / f"eval_{args.split}{f'_smoke{args.smoke}' if args.smoke else ''}.jsonl"
    done = {json.loads(x)["config"] for x in out.read_text().splitlines()} if out.exists() else set()
    for name, (make, iterative) in configs(args.extra).items():
        if (args.only and name not in args.only) or name in done:
            continue
        t0 = time.time()
        orders = rank_all(build(make()), tok, rows, iterative)
        hit5 = [int(np.array(gold_mask(r), bool)[o[:5]].sum() == sum(gold_mask(r))) for r, o in zip(rows, orders)]
        with out.open("a") as fh:
            fh.write(json.dumps({"config": name, "iterative": iterative, "ids": [r["id"] for r in rows],
                                 "orders": orders, "recall5": round(float(np.mean(hit5)), 4),
                                 "seconds": round(time.time() - t0)}) + "\n")
        print(name, round(float(np.mean(hit5)), 4), round(time.time() - t0), "s", flush=True)

from functools import lru_cache
from pathlib import Path

HERE = Path(__file__).resolve().parent
FILES = {"dev": "musique_ans_v1.0_dev.jsonl", "pool": "musique_ans_v1.0_train.jsonl"}
SPLITS = {"dev300": "dev", "test": "dev", "train": "pool"}  # split -> source file


@lru_cache(maxsize=None)
def _file(src: str) -> dict:
    with open(HERE.parent / "exp08_musique" / "data" / FILES[src], encoding="utf-8") as fh:
        return {r["id"]: r for r in map(json.loads, fh)}


def load(split: str) -> list[dict]:
    ids = json.loads((HERE / "split_ids.json").read_text())[split]
    rows = _file(SPLITS[split])
    return [rows[i] for i in ids]


def paragraphs_of(row: dict) -> tuple[list[str], list[str]]:
    """'<title>. <text>' as in exp02."""
    ps = sorted(row["paragraphs"], key=lambda p: p["idx"])
    titles = [p["title"].strip() for p in ps]
    return titles, [f"{t}. {p['paragraph_text'].strip()}" for t, p in zip(titles, ps)]


def gold_mask(row: dict) -> list[int]:
    return [int(p["is_supporting"]) for p in sorted(row["paragraphs"], key=lambda p: p["idx"])]


def hops(row: dict) -> int:
    return len(row["question_decomposition"])


def build_retrieval_prompt(question: str, paragraphs: list[str]) -> str:
    """exp02/BRACIS prompt; only change: 'the HotpotQA question' -> 'the question'."""
    context_str = "\n\n".join([f"[{i + 1}] {p}" for i, p in enumerate(paragraphs)])
    return f"""Answer the question using only the provided context.

Rules:
- Output only the final answer.
- If the answer is yes, no or noanswer, output exactly: yes or no or noanswer.
- Otherwise output a short span or entity name only.
- Do not include any explanation.
- Do not repeat the question.
- If multiple positions/titles are mentioned, output only the one that
  directly answers the question.

Context:
{context_str}

Question: {question}

Answer:"""


_ENC = None


def n_tokens(text: str) -> int:
    global _ENC
    if _ENC is None:
        import tiktoken

        _ENC = tiktoken.get_encoding("o200k_base")
    return len(_ENC.encode(text))


def chain(row: dict) -> list[int]:
    """Gold paragraph positions (in paragraphs_of order) in decomposition (hop) order."""
    pos = {p["idx"]: i for i, p in enumerate(sorted(row["paragraphs"], key=lambda p: p["idx"]))}
    return [pos[d["paragraph_support_idx"]] for d in row["question_decomposition"]]


def query(question: str, selected: list[str]) -> str:
    """Question + selected paragraphs, most recent first (truncation cuts the oldest)."""
    return " [SEP] ".join([question, *reversed(selected)])


def encode(tok, qs, ps, max_length=512):
    """Truncate the query side only (PROTOCOL); if a paragraph alone exceeds max_length, fall back to longest_first."""
    try:
        return tok(qs, ps, truncation="only_first", max_length=max_length, padding=True, return_tensors="pt")
    except Exception:  # noqa: BLE001 - tokenizers raises a bare Exception for this case
        return tok(qs, ps, truncation="longest_first", max_length=max_length, padding=True, return_tensors="pt")
"""Fine-tune A1 on MuSiQue train (PROTOCOL.md). Resumable; checkpoints every --save-every steps.

  uv run python train.py --mode iter --tag m1_iter      # all steps t = 0..h-1
  uv run python train.py --mode step0 --tag m1          # step-0 examples only (same draw)
  uv run python train.py --mode iter --tag smoke --smoke 40   # throughput test, nothing kept
"""

from __future__ import annotations

import argparse
import json
import math
import random
import time
from pathlib import Path

import numpy as np
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

from data import chain, encode, load, paragraphs_of, query

HERE = Path(__file__).resolve().parent
A1 = HERE.parent / "exp04_astra_edit" / "models" / "a1"
torch.set_num_threads(8)


def examples(rows, mode, n_neg=6):
    """(query, paragraph, label). Negatives are seeded per (question, step), so step0 = iter's step-0 subset."""
    out = []
    for qi, r in enumerate(rows):
        _, paras = paragraphs_of(r)
        ch = chain(r)
        non = [i for i in range(len(paras)) if i not in ch]
        for t in range(len(ch) if mode == "iter" else 1):
            rng = np.random.default_rng([qi, t])
            q = query(r["question"], [paras[i] for i in ch[:t]])
            out += [(q, paras[i], 1.0) for i in ch[t:]]
            out += [(q, paras[i], 0.0) for i in rng.choice(non, n_neg, replace=False)]
    return out


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--mode", choices=("iter", "step0"), required=True)
    ap.add_argument("--tag", required=True)
    ap.add_argument("--n-questions", type=int, default=2000)
    ap.add_argument("--batch", type=int, default=16)
    ap.add_argument("--lr", type=float, default=2e-5)
    ap.add_argument("--max-len", type=int, default=512)
    ap.add_argument("--save-every", type=int, default=500)
    ap.add_argument("--smoke", type=int, default=0, help="run this many steps, report throughput, save nothing")
    args = ap.parse_args()
    torch.manual_seed(0)

    rows = load("train")
    # seeded random subset (deviation 1 in results/budget.json: the train ids are sorted, so "first N" = 2-hop only)
    rows = [rows[i] for i in sorted(np.random.default_rng(9).permutation(len(rows))[: args.n_questions])]
    pairs = examples(rows, args.mode)
    out = HERE / "models" / args.tag
    out.mkdir(parents=True, exist_ok=True)
    ckpt = out / "checkpoint.pt"
    print(f"mode={args.mode} questions={len(rows)} pairs={len(pairs)} pos={sum(p[2] for p in pairs):.0f}", flush=True)

    tok = AutoTokenizer.from_pretrained(str(A1))
    model = AutoModelForSequenceClassification.from_pretrained(str(A1))
    opt = torch.optim.AdamW(model.parameters(), lr=args.lr, weight_decay=0.01)
    total = math.ceil(len(pairs) / args.batch)
    warm = max(1, int(0.1 * total))
    sched = torch.optim.lr_scheduler.LambdaLR(
        opt, lambda s: min(1.0, (s + 1) / warm) * max(0.0, (total - s) / max(1, total - warm)))
    step, secs = 0, 0.0
    if ckpt.exists() and not args.smoke:
        st = torch.load(ckpt)
        model.load_state_dict(st["model"]); opt.load_state_dict(st["opt"]); sched.load_state_dict(st["sched"])
        step, secs = st["step"], st["secs"]
        print(f"resumed at step {step}/{total}", flush=True)
    order = list(range(len(pairs)))
    random.Random(0).shuffle(order)
    model.train()
    t0 = time.time()
    while step < total:
        idx = order[step * args.batch:(step + 1) * args.batch]
        q, p, y = zip(*(pairs[i] for i in idx))
        enc = encode(tok, list(q), list(p), args.max_len)
        loss = torch.nn.functional.binary_cross_entropy_with_logits(model(**enc).logits.squeeze(-1), torch.tensor(y))
        opt.zero_grad(); loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step(); sched.step(); step += 1
        if step % 50 == 0 or (args.smoke and step % 10 == 0):
            el = secs + time.time() - t0
            print(f"step {step}/{total} loss {loss.item():.4f} {el / 60:.1f} min, eta {el / step * (total - step) / 60:.0f} min",
                  flush=True)
        if args.smoke and step >= args.smoke:
            rate = (time.time() - t0) / step
            print(json.dumps({"sec_per_step": round(rate, 2), "steps": total, "projected_h": round(rate * total / 3600, 2)}))
            return
        if step % args.save_every == 0:
            torch.save({"model": model.state_dict(), "opt": opt.state_dict(), "sched": sched.state_dict(),
                        "step": step, "secs": secs + time.time() - t0}, ckpt)
    model.save_pretrained(out / "model"); tok.save_pretrained(out / "model")
    (out / "train_info.json").write_text(json.dumps(
        {**vars(args), "questions": len(rows), "pairs": len(pairs), "steps": total,
         "train_minutes": round((secs + time.time() - t0) / 60, 1)}, indent=1))
    ckpt.unlink(missing_ok=True)
    print("done", flush=True)


if __name__ == "__main__":
    main()

  10:

  12: 2. **Secondary (H9, de-confounded):** is the change that adds *only* query conditioning, D = M1-iter âˆ’ M1-ctrl, still low-rank?

  14: ## The control model: M1-ctrl
  15: 
  16: - `train.py --mode ctrl` builds **M1-iter's exact example list**: the same questions (exp09's seeded 1,000), the same positives per step (the remaining gold), the same negative draws (seeded per question and step), the same shuffle, batch 16, lr 2e-5, 1 epoch, max length 512, seed 0, initialised from A1.

  19: - The resulting model has seen exactly what M1-iter saw, minus the conditioning. The positive mix also matches: later-hop gold is over-represented, as in M1-iter.
  20: - **Not retrained:** M1 and M1-iter, frozen from exp09. M1-iter's rankings come from exp09 (identical to a re-run, exp10 check).

### 1. Matching and implementation

### 2. Statistical decision rules

- The stated McNemar power is conditional on about 90 discordant cases; after matching, the discordance rate and effect may differ. A non-significant result is not evidence of equivalence. The protocol acknowledges limited power, but should pre-register the paired effect CI and a practical-null margin ([PROTOCOL.md:45–50](</C:/code/qualiusp2026/experiments/exp12_matched_control/PROTOCOL.md:45>)).
- There are two “confirmatory” claims at α=.05 with no family-wise adjustment ([PROTOCOL.md:63](</C:/code/qualiusp2026/experiments/exp12_matched_control/PROTOCOL.md:63>)). **Before running:** use Holm across H6/H9 or explicitly label the error rates as per-claim.
- The secondary gain gate (`≥.05` on 300 dev cases) and 80% recovery threshold are noisy point-estimate cutoffs; the denominator can be small or unstable ([PROTOCOL.md:51–55](</C:/code/qualiusp2026/experiments/exp12_matched_control/PROTOCOL.md:51>)). **Before running:** define behavior for a zero/sign-changing test denominator and report the paired CI for the raw gain as well as recovery.
- Bootstrap recovery should resample question IDs jointly across `g_r*`, `ctrl_iter`, and M1-iter; ratio intervals can be unbounded or misleading when the denominator approaches zero. Specify the bootstrap method, replicate count, and handling of invalid ratios before seeing results.

### 3. What a positive result would still not establish

- It would not show that **conditioning alone** caused the gain: the primary also changes inference policy and training-query distribution. The same-inference factorial comparison above is the cheap isolating check.
- It would not show robustness to random seed: “all 3 pairs win” is descriptive, with only three GPU seeds and no uncertainty estimate ([PROTOCOL.md:25–29](</C:/code/qualiusp2026/experiments/exp12_matched_control/PROTOCOL.md:25>)). Report the paired seed differences; don’t treat three wins as a powered replication.
- A successful low-rank graft may reflect this exact base, seed, hardware, and test set; the random-rank control is only a weak comparator. Add a cheap check of `g_r2` against the GPU seed-0 delta and report per-question gains, alongside the registered random control.
