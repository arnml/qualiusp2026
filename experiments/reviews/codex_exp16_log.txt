   2: 
   3: Rows are normalized to {"id", "question", "paras": ["<title>. <text>", ...], "gold": [0/1 per paragraph],
   4: "chain": [gold positions in hop order], "type"}. Chain order = first appearance of each title in supporting_facts.
   5: DATA_DIR holds hotpot_{train0,train1,validation}.parquet and twowiki_{train,dev}.parquet.
   6: """
   7: 
   8: from __future__ import annotations
   9: 
  10: import json
  11: import os
  12: from functools import lru_cache

  14: 
  15: import numpy as np
  16: import pyarrow.parquet as pq
  17: 
  18: HERE = Path(__file__).resolve().parent

  20: FILES = {"hp_eval": ["hotpot_validation.parquet"], "hp_train": ["hotpot_train0.parquet", "hotpot_train1.parquet"],
  21:          "tw_eval": ["twowiki_dev.parquet"], "tw_train": ["twowiki_train.parquet"]}
  22: N_TRAIN, TRAIN_SEED = 1000, 16
  23: 
  24: 
  25: def _norm_hotpot(r):
  26:     titles, sents = r["context"]["title"], r["context"]["sentences"]
  27:     sf = list(dict.fromkeys(r["supporting_facts"]["title"]))
  28:     return titles, ["".join(s).strip() for s in sents], sf, r["type"]
  29: 
  30: 
  31: def _norm_twowiki(r):
  32:     ctx = json.loads(r["context"]); sf = list(dict.fromkeys(s[0] for s in json.loads(r["supporting_facts"])))
  33:     return [c[0] for c in ctx], [" ".join(c[1]).strip() for c in ctx], sf, r["type"]
  34: 
  35: 
  36: def _row(r, ds):
  37:     titles, texts, sf, typ = (_norm_hotpot if ds == "hp" else _norm_twowiki)(r)
  38:     pos = {t: i for i, t in enumerate(titles)}
  39:     chain = [pos[t] for t in sf if t in pos]
  40:     assert len(chain) == len(sf), "supporting title missing from context"
  41:     gold = [int(i in chain) for i in range(len(titles))]
  42:     return {"id": r["id"] if ds == "hp" else r["_id"], "question": r["question"],
  43:             "paras": [f"{t.strip()}. {x}" for t, x in zip(titles, texts)], "gold": gold, "chain": chain, "type": typ}
  44: 
  45: 
  46: @lru_cache(maxsize=None)
  47: def _table(key):
  48:     rows = []
  49:     for f in FILES[key]:
  50:         rows += pq.read_table(DATA / f).to_pylist()
  51:     ds = key[:2]
  52:     return {(r["id"] if ds == "hp" else r["_id"]): r for r in rows}
  53: 
  54: 
  55: def load(split):
  56:     """split in {hp_test, hp_tune, tw_test, tw_tune, hp_train, tw_train}."""
  57:     ds = split[:2]
  58:     if split.endswith("train"):  # PROTOCOL: seeded sample of N_TRAIN sorted training ids
  59:         tab = _table(f"{ds}_train"); ids = sorted(tab)
  60:         ids = sorted(ids[i] for i in np.random.default_rng(TRAIN_SEED).permutation(len(ids))[:N_TRAIN])
  61:     else:
  62:         tab = _table(f"{ds}_eval"); ids = json.loads((HERE / "split_ids.json").read_text())[split]
  63:     return [_row(tab[i], ds) for i in ids]
  64: 
  65: 
  66: def query(question, selected):
  67:     """Question + selected paragraphs, most recent first (as exp09-exp13)."""
  68:     return " [SEP] ".join([question, *reversed(selected)])
  69: 
  70: 
  71: def encode(tok, qs, ps, max_length=512):
  72:     try:
  73:         return tok(qs, ps, truncation="only_first", max_length=max_length, padding=True, return_tensors="pt")
  74:     except Exception:  # noqa: BLE001 - paragraph alone exceeds max_length
  75:         return tok(qs, ps, truncation="longest_first", max_length=max_length, padding=True, return_tensors="pt")

  36:     for n in base:
  37:         if d[n].dim() == 2 and min(d[n].shape) > r:
  38:             U, S, Vh = torch.linalg.svd(d[n], full_matrices=False)
  39:             part = (U[:, :r] * S[:r]) @ Vh[:r]
  40:             if rand:
  41:                 R = torch.randn(d[n].shape[0], r, generator=g) @ torch.randn(r, d[n].shape[1], generator=g)
  42:                 part = R * (part.norm() / R.norm())
  43:             out[n] = base[n] + part
  44:         else:
  45:             out[n] = base[n] + d[n]
  46:     return out
  47:

   1: # exp12: pair-matched control for the iterative ranker
   2: 
   3: Pre-registered in [PROTOCOL.md](PROTOCOL.md): commit 975371a, revised after an adversarial pre-run review by Codex.
   4: - **Control:** M1-ctrl is trained on M1-iter's **exact** 18,101 training pairs in the same order, with the query prefix of picked paragraphs removed.

   7: 
   8: ## Bottom line
   9: 
  10: 1. **Primary fails: once training data is matched, iteration's overall gain is small and not significant.** M1-iter (iterative inference) vs M1-ctrl (one-shot), test recall@5:
  11:    - **0.7475 vs 0.7075, +0.040 [âˆ’0.005, +0.085]**, 52 vs 36 discordant questions, p = 0.109.
  12:    - The minimum detectable effect was about 0.07, so this does not show "no effect".
  13: 2. **The small gain is consistent across seeds:** +0.040 / +0.028 / +0.033 (mean +0.033, SD 0.006). It is positive in all 3 seeds (descriptive).
  14: 3. **exp09's +0.068 splits roughly into two parts:**
  15:    - **+0.025 from more training:** M1-ctrl vs exp09's M1, 12 vs 2 discordant questions, p = 0.013 (descriptive).
  16:    - **about +0.04 from conditioning:** not significant.
  17:    - So H6 ("iteration beats one-shot") is **not confirmed** once the confound is removed.
  18: 4. **The advantage is concentrated in 4-hop chains (exploratory, uncorrected).** 4-hop: **0.578 vs 0.391** (20 vs 8 discordant questions, p = 0.036, n = 64). 2-hop: 0.823 vs 0.813. 3-hop: 0.714 vs 0.699.
  19: 5. **Secondary holds: the pure conditioning change is rank 2.** D = M1-iter âˆ’ M1-ctrl, grafted onto M1-ctrl at rank 2, recovers **86.8% [77.7, 95.8]** of the gain on test (iterative inference: 0.4075 â†’ 0.7025, full 0.7475).
  20:    - The norm-matched random rank-2 control recovers 7% on dev300, against 85% for the real rank 2.
  21:    - **What this change does:** it is the skill of *reading* a conditioned query. Without it, M1-ctrl collapses when run iteratively (0.41). The change is functionally rank 2, even though its benefit over a matched one-shot ranker is small overall.

===== experiments/exp16_rank2_replication/analyze.py =====
   1: """exp16 pre-registered analysis (PROTOCOL.md). Written before any exp16 model was trained.
   2: 
   3:   python analyze.py      # RESULTS_DIR: eval_{hp,tw}_{tune,test}.jsonl -> results.json
   4: """
   5: 
   6: from __future__ import annotations
   7: 
   8: import json
   9: import os
  10: from pathlib import Path
  11: 
  12: import numpy as np
  13: from scipy.stats import binomtest
  14: 
  15: from data import load
  16: 
  17: HERE = Path(__file__).resolve().parent
  18: RES = Path(os.environ.get("RESULTS_DIR", HERE / "results"))
  19: B = 5000
  20: RANKS = (1, 2, 4, 8)
  21: 
  22: 
  23: def evals(split):
  24:     rows = load(split); out = {}
  25:     for line in (RES / f"eval_{split}.jsonl").read_text().splitlines():
  26:         j = json.loads(line)
  27:         assert j["ids"] == [r["id"] for r in rows], f"ids differ {split}"
  28:         assert j["config"] not in out, f"duplicate {split} {j['config']}"
  29:         out[j["config"]] = j["orders"]
  30:     return rows, out
  31: 
  32: 
  33: def hits(rows, orders, slack=1, k=None):
  34:     """Full-support recall: all gold paragraphs within the top (|gold| + slack), or within the top k if k is given."""
  35:     res = []
  36:     for r, o in zip(rows, orders):
  37:         g = np.array(r["gold"], bool); kk = k if k else int(g.sum()) + slack
  38:         res.append(int(g[o[:kk]].sum() == g.sum()))
  39:     return np.array(res)
  40: 
  41: 
  42: def recovery(g, base, full):
  43:     den = full.mean() - base.mean()
  44:     return float((g.mean() - base.mean()) / den) if den > 0 else 0.0
  45: 
  46: 
  47: def mcnemar(x, y):
  48:     b, c = int(((x == 1) & (y == 0)).sum()), int(((x == 0) & (y == 1)).sum())
  49:     return {"only_x": b, "only_y": c, "p": float(binomtest(b, b + c, 0.5).pvalue) if b + c else 1.0}
  50: 
  51: 
  52: def main():
  53:     rng, rep = np.random.default_rng(0), {}
  54:     for ds in ("tw", "hp"):
  55:         rows_t, tu = evals(f"{ds}_tune"); rows, te = evals(f"{ds}_test")
  56:         H = lambda R, E, c: hits(R, E[c])
  57:         base_t, full_t = H(rows_t, tu, "ctrl_iter"), H(rows_t, tu, "iter_iter")
  58:         gap = float(full_t.mean() - base_t.mean())
  59:         rec_t = {r: round(recovery(H(rows_t, tu, f"g_r{r}"), base_t, full_t), 3) for r in RANKS}
  60:         rand_t = recovery(H(rows_t, tu, "g_rand_r2"), base_t, full_t)
  61:         d = {"tune": {"gap": round(gap, 4), "recovery": rec_t, "rand_r2": round(rand_t, 3),
  62:                       "rstar_80": next((r for r in RANKS if rec_t[r] >= 0.8), None)}}
  63:         d["gate_gap_ge_0.05"] = gap >= 0.05
  64:         d["control_passes"] = bool(rand_t < 0.5 * rec_t[2])
  65:         b0, f0 = H(rows, te, "ctrl_iter"), H(rows, te, "iter_iter")
  66:         g2 = H(rows, te, "g_r2"); n = len(g2)
  67:         bs = [recovery(g2[i], b0[i], f0[i]) for i in (rng.integers(0, n, n) for _ in range(B))]
  68:         ci = [float(np.percentile(bs, 2.5)), float(np.percentile(bs, 97.5))]
  69:         d["test"] = {"ctrl_iter": round(float(b0.mean()), 4), "iter_iter": round(float(f0.mean()), 4), "g_r2": round(float(g2.mean()), 4),
  70:                      "recovery_r2": round(recovery(g2, b0, f0), 3), "recovery_r2_ci95": ci,
  71:                      "recovery_other_ranks": {r: round(recovery(H(rows, te, f"g_r{r}"), b0, f0), 3) for r in RANKS if f"g_r{r}" in te}}
  72:         d["holds"] = bool(d["gate_gap_ge_0.05"] and d["control_passes"] and d["test"]["recovery_r2"] >= 0.8 and ci[0] > 0.5)
  73:         d["status"] = "not testable (tune gap < 0.05)" if not d["gate_gap_ge_0.05"] else ("holds" if d["holds"] else "fails")
  74:         # descriptive: 2x2 and the iteration effect (system comparison), by question type
  75:         two = {c: round(float(H(rows, te, c).mean()), 4) for c in ("iter_iter", "iter_oneshot", "ctrl_iter", "ctrl_oneshot")}
  76:         x, y = f0, H(rows, te, "ctrl_oneshot")
  77:         types = sorted({r["type"] for r in rows}); ty = np.array([r["type"] for r in rows])
  78:         d["descriptive"] = {"two_by_two": two, "iter_vs_oneshot": {"diff": round(float((x - y).mean()), 4), **mcnemar(x, y)},
  79:                             "by_type_iter_minus_oneshot": {t: round(float((x - y)[ty == t].mean()), 4) for t in types},
  80:                             "recall_at_5": {c: round(float(hits(rows, te[c], k=5).mean()), 4) for c in ("iter_iter", "ctrl_oneshot", "g_r2")}}
  81:         rep[ds] = d
  82:     rep["replication"] = {"datasets_holding": [k for k in ("tw", "hp") if rep[k]["holds"]],
  83:                           "with_musique_exp12": "MuSiQue (exp12): rank-2 recovery 0.868 [0.777, 0.958], holds"}
  84:     (RES / "results.json").write_text(json.dumps(rep, indent=1))
  85:     print(json.dumps(rep, indent=1))
  86: 
  87: 
  88: if __name__ == "__main__":

## Null case

1. **Training data provenance is not locked.** The notebook checks hashes for the evaluation files, but only prints abbreviated hashes for the training files; a changed or corrupted training file would not stop the run ([make_notebook.py:27–36](experiments/exp16_rank2_replication/make_notebook.py:27)). Add fixed SHA-256 assertions for all three training parquet files before training.

2. **The HotpotQA exclusion is a claim, not a checked invariant.** The protocol says the 1,300 evaluation IDs exclude IDs used in exp01–exp07, but the notebook and `data.load` do not verify that exclusion ([PROTOCOL.md:16](experiments/exp16_rank2_replication/PROTOCOL.md:16), [data.py:55–63](experiments/exp16_rank2_replication/data.py:55)). Add an assertion against the historical ID lists before training or evaluation. The supplied `split_ids.json` has disjoint tune/test sets of 300/1,000 IDs per dataset, but that alone does not establish the historical exclusion ([split_ids.json:1](experiments/exp16_rank2_replication/split_ids.json:1)).

3. **The pair match is real but narrower than “identical training.”** The control assertion checks equal labels, paragraphs, and pair order, not queries ([train.py:31–41, 55–57](experiments/exp16_rank2_replication/train.py:31)). Different query lengths change truncation and padded batch shapes; with dropout, the same seed does not ensure equivalent stochastic training noise. Report per-pair encoded lengths and truncation rates by mode, and add a seed-matched control-vs-control delta to show whether a rank-2 graft can recover ordinary run variation.

4. **Truncation may discard conditioning context.** Both training and inference use `truncation="only_first"` except when a paragraph alone exceeds the limit ([data.py:71–75](experiments/exp16_rank2_replication/data.py:71)). Because the query puts the question first and selected paragraphs afterward, long queries can lose their later context; the “most recent first” ordering means older selected paragraphs are especially likely to be dropped ([data.py:66–68](experiments/exp16_rank2_replication/data.py:66)). Record token-length/truncation rates by step and dataset; report a cheap untruncated-to-limit sensitivity subset or explicitly scope the claim to the retained context.

5. **The training/evaluation hardware is not enforced as specified.** Training and evaluation accept any CUDA device; the notebook only prints the GPU name ([train.py:27, 51](experiments/exp16_rank2_replication/train.py:27), [evaluate.py:25, 88](experiments/exp16_rank2_replication/evaluate.py:25), [make_notebook.py:39–40](experiments/exp16_rank2_replication/make_notebook.py:39)). Assert T4 in the notebook and save the GPU name, library versions, and determinism settings in run metadata. This matters because only one seed is preregistered.

6. **The primary metric is easier and has a different ceiling from exp12.** Exp16 counts full support within `|gold|+1` among only 10 paragraphs; exp12’s cited result is recall@5 on MuSiQue ([PROTOCOL.md:33–35](experiments/exp16_rank2_replication/PROTOCOL.md:33), [exp12 README:19](experiments/exp12_matched_control/README.md:19)). A positive replication would support transfer of the graft result under this new metric, not equivalence to the original effect size. Add a preregistered fixed-k sensitivity using the same k across datasets, and show results by support count/type.

7. **The recovery ratio is unstable when the denominator is small.** The gate is a *tuning-set point estimate* of a 0.05 gap, while the test ratio divides by the test-set gap ([PROTOCOL.md:48–52](experiments/exp16_rank2_replication/PROTOCOL.md:48), [analyze.py:42–45, 65–72](experiments/exp16_rank2_replication/analyze.py:42)). The bootstrap maps every nonpositive resampled denominator to recovery 0, which does not represent an ordinary ratio interval. Require a positive test gap with a confidence bound, and use a ratio method that handles a near-zero denominator (e.g. Fieller), or make the primary test a paired difference in graft vs. full-model hits.

8. **The bootstrap interval is not a decision rule with a stated error rate.** A percentile CI over 5,000 paired question resamples is used as a threshold test, with no calibration or power justification; denominator instability can make its behavior hard to interpret ([PROTOCOL.md:51–53](experiments/exp16_rank2_replication/PROTOCOL.md:51), [analyze.py:67–72](experiments/exp16_rank2_replication/analyze.py:67)). Pre-register a minimum detectable effect / power calculation and define how an inconclusive interval is classified.

9. **Multiplicity depends on the wording of the conclusion.** Requiring both datasets to hold is a conjunctive claim, for which no correction is needed to claim “both”; saying “partial” when either one holds is a disjunctive claim and inflates false positives without correction ([PROTOCOL.md:53–63](experiments/exp16_rank2_replication/PROTOCOL.md:53)). Either label one-dataset success exploratory or adjust the partial-claim rule.

10. **The random graft does not rule out training-run noise.** It is compared with the real rank-2 graft only on tuning data, while both models come from one seed ([PROTOCOL.md:41, 49](experiments/exp16_rank2_replication/PROTOCOL.md:41)). A positive result could reflect a seed-specific parameter difference whose leading directions happen to help. Add a cheap seed-matched null delta if compute permits; otherwise narrow the conclusion to “the rank-2 component of this single fitted delta transfers on the held-out questions.”

11. **Other positive-result alternatives:** HotpotQA A1 was fine-tuned on the full HotpotQA training split, including the source of exp16’s training sample ([PROTOCOL.md:20](experiments/exp16_rank2_replication/PROTOCOL.md:20)); this can make the experiment benchmark-specific even if the pair comparison is fair. Report the result as adaptation of A1, and add a run from a checkpoint without HotpotQA fine-tuning before claiming dataset-general transfer.

12. **Concrete pre-run priorities:** (1) hard-check all training-file hashes and Hotpot historical-ID exclusions; (2) log token lengths/truncation by step and mode; (3) preregister a denominator-stable recovery rule, power rationale, and treatment of the “partial” claim; (4) enforce/log T4 and software versions; (5) add a seed-noise null or qualify the single-seed claim.
