## Terminology convention

- **selector / reranker / ranker.** Use **selector** for the model in this work (it chooses what the LLM reads). Use **reranker** only for the general model class and for cited work (Background, Related Work, positioning table). Drop **ranker** (05_results:32, 37, 63, 65; 01_introduction:18--19; 06_plan RQ table). For procedures, use **one-shot selection** and **iterative selection** (not "one-shot ranking", "iterative ranker", "always-iterative ranking"); for models, use the names (M1-iter, M1-ctrl) or "the iterative model / the one-shot model".
- **Metric.** Define once in 02_background:37: "Below, recall@$k$ always denotes full-support recall@$k$." Then use **recall@5** (and recall@($|\text{gold}|+1$)) everywhere. Do not use "coverage", "full coverage", "hit@5" or "evidence recall" for this quantity. In the abstract and resumo, write "full-support recall" with a one-clause definition.
- **iterative / conditioned / conditioning.** **Conditioning** = putting already-selected paragraphs into the query (a property of training and of the query). **Iterative** = the greedy inference procedure. Write "conditioning-trained iterative selection" when both matter. Use **conditioned query** for the query text. Use "chain-following" only as an informal gloss in the Introduction and hypothesis, not in results.
- **The two weight changes.** **Iteration change** = M1-iter $-$ M1 (confounded by training data, Sec. 5.4). **Conditioning change** = M1-iter $-$ M1-ctrl (the main result). Use **weight change $\Delta$** consistently; use "update" only in the generic Background sense and "delta" only in the method name.
- **graft / adapter.** **Rank-$r$ graft** = the truncated SVD of an extracted $\Delta$ added to a model (all current results). **Chain adapter** = the planned, directly trained low-rank module (W1, Figure 1b, Figure 6.1). Do not call the extracted graft an adapter in the results; do not call either one an "artifact".
- **Functional rank.** Define "functionally rank $r$" once (02_background:32), then use "functional rank". State recovery values to one decimal where the text reports them (84.7\%, 86.8\%, 97.1\%, 92.1\%), never "about 85\%".
- **Data.** Use **unused** (questions not used in any earlier experiment) instead of "fresh".
- **Test status words.** "was supported / was not supported" for pre-registered hypotheses; "exploratory" and "descriptive" as status labels; avoid "failed", "succeeded", "did not help", "beat" (use "outperformed" or "exceeded").
